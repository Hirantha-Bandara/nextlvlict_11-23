# Edu Bloom

Design a premium, modern, responsive educational portfolio website for a Sri Lankan A/L tuition teacher using React, Vite, TypeScript, Tailwind CSS, and Framer Motion.

The website should be inspired by the overall structure and content flow of a traditional tuition teacher website, but redesigned with a modern 2026 UI/UX. Do NOT create an outdated WordPress-looking design. Instead, create a clean, premium, minimal, and highly professional landing page.

Design Style:

- Modern educational branding

- Premium appearance

- Clean white backgrounds

- Navy blue (#163B6D) as primary color

- Bright red (#E53935) as accent color

- Soft gray backgrounds for alternate sections

- Large rounded corners (16-24px)

- Soft shadows

- Smooth spacing

- Excellent typography hierarchy

- Glass effect only where appropriate

- Mobile-first responsive design

- Framer Motion animations (fade-up, stagger, hover, counters)

Homepage Structure:

1. Transparent Navbar

- Logo

- Large teacher portrait on the right

3. Statistics Section

Animated counters:

4. About Teacher

- Professional image

6. Top Rank Students

Premium cards showing:

7. Study Materials

Modern masonry gallery with hover zoom and lightbox.

Modern cards with:

11. Class Schedule

Beautiful responsive timetable cards instead of HTML tables.

12. Course Fees

Premium pricing cards including:

Animated accordion.

14. Contact Section

Two-column layout:

15. Footer

UI Requirements:

- Plenty of whitespace

- Rounded cards

- Soft gradients

- Large section spacing

- Modern icons (Lucide React)

- Smooth hover effects

- Consistent design system

- No Bootstrap appearance

- No WordPress style boxes

- No outdated gradients

- Premium landing page quality similar to Stripe, Linear, Vercel, or modern SaaS websites, adapted for an educational brand.

Technology Requirements:

- React

- Vite

- TypeScript

- Tailwind CSS

- Framer Motion

- Lucide React icons

- Fully responsive

- Component-based architecture

- Clean folder structure

- Reusable UI components


Use the attached reference website only as inspiration for the content structure and section order. Do not copy the visual design. Create a significantly more modern, premium, responsive, and professional UI while preserving a similar educational portfolio layout.
