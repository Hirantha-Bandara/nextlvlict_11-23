Date captured: 2026-05-19

==================================================
1) OVERVIEW
==================================================
The class fee payment feature is implemented in the frontend as:
- Student-side payment page: src/pages/ClassFeePayment.tsx
- Route mapping: src/App.tsx (/payment)
- Dashboard quick access: src/pages/Dashboard.tsx
- Optional nav entry: src/components/DashboardNav.tsx
- Admin-side verification: src/pages/AdminDashboard.tsx (and also src/pages/PaymentVerifications.tsx)
- Shared request wrapper (now axios-based): src/lib/utils.ts (apiFetch)

The student flow is:
1. Load fee details and payment history from backend.
2. If fee is pending/overdue, allow payment initiation.
3. Receive payment payload from backend and POST to PayHere sandbox.
4. Return/cancel status is handled via URL query params.

The admin flow is:
1. Load payment records from PaymentVerificationServlet.
2. Verify or reject with notes/reason.
3. Refresh records after action.

3) STUDENT CLASS FEE PAYMENT LOGIC
==================================================
File: src/pages/ClassFeePayment.tsx

3.1 Fetch current fee details
Backend endpoint used:
- GET ClassFee?action=getFeeDetails&studentId={studentId}

CODE:
--------------------------------------------------
const response = await apiFetch(
  `ClassFee?action=getFeeDetails&studentId=${studentId}`,
  {
    method: 'GET',
    credentials: 'include',
    headers: { 'Accept': 'application/json' }
  }
);

if (response.status === 401 || response.status === 403) {
  handleSessionExpired();
  return;
}

if (!response.ok) throw new Error(`HTTP error! status: ${response.status}`);

const data = await response.json();
if (data.success) {
  setFeeDetails(data.feeDetails);
} else {
  setError(data.message || 'Failed to fetch fee details');
}
--------------------------------------------------

3.2 Fetch payment history
Backend endpoint used:
- GET PaymentHistoryServlet

CODE:
--------------------------------------------------
const response = await apiFetch(
  'PaymentHistoryServlet',
  {
    method: 'GET',
    credentials: 'include',
    headers: { 'Accept': 'application/json' }
  }
);

if (response.ok) {
  const data = await response.json();
  if (data.success) {
    setPaymentHistory(data.payments || []);
  }
}
--------------------------------------------------

3.3 Initiate payment
Backend endpoint used:
- GET ClassFee?action=initiatePayment&studentId={studentId}

CODE:
--------------------------------------------------
const response = await apiFetch(
  `ClassFee?action=initiatePayment&studentId=${studentId}`,
  {
    method: 'GET',
    credentials: 'include'
  }
);

const data = await response.json();
if (data.success && data.paymentData) {
  submitToPayHere(data.paymentData);
} else {
  setError(data.message || 'Failed to initiate payment');
  toast.error(data.message || 'Payment initiation failed');
}
--------------------------------------------------

3.4 Redirect to PayHere sandbox
The frontend builds an HTML form and submits to:
- https://sandbox.payhere.lk/pay/checkout

Required fields checked before submit:
- merchant_id, return_url, cancel_url, notify_url
- first_name, last_name, email, phone
- address, city, country
- order_id, items, currency, amount, hash

CODE:
--------------------------------------------------
const form = document.createElement('form');
form.method = 'POST';
form.action = 'https://sandbox.payhere.lk/pay/checkout';

requiredParams.forEach(key => {
  const input = document.createElement('input');
  input.type = 'hidden';
  input.name = key;
  input.value = paymentData[key];
  form.appendChild(input);
});

document.body.appendChild(form);
setTimeout(() => {
  form.submit();
}, 100);
--------------------------------------------------

3.5 Handle return/cancel after gateway redirect
CODE:
--------------------------------------------------
const urlParams = new URLSearchParams(window.location.search);
const action = urlParams.get('action');

if (action === 'paymentReturn') {
  toast.success("Payment completed successfully!");
  fetchFeeDetails(studentId);
  fetchPaymentHistory();
  window.history.replaceState({}, document.title, window.location.pathname);
} else if (action === 'paymentCancel') {
  toast.error("Payment was cancelled");
  window.history.replaceState({}, document.title, window.location.pathname);
}
--------------------------------------------------

==================================================
5) REQUEST LAYER (AXIOS)
==================================================
All the above calls use apiFetch from src/lib/utils.ts.
apiFetch now internally uses axios and returns a Response-like object
(so existing response.ok/response.json()/response.headers.get() code still works).

CODE (core):
--------------------------------------------------
const axiosResponse = await axios.request({
  url,
  method,
  headers,
  data,
  responseType: 'json',
});

const resp: Partial<Response> = {
  ok: axiosResponse.status >= 200 && axiosResponse.status < 300,
  status: axiosResponse.status,
  statusText: axiosResponse.statusText,
  json: async () => axiosResponse.data,
  text: async () => (typeof axiosResponse.data === 'string' ? axiosResponse.data : JSON.stringify(axiosResponse.data)),
  headers: {
    get: (name: string) => responseHeaders.get(name.toLowerCase()) || null,
  } as any,
};

==================================================
